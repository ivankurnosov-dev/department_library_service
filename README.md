# Электронная библиотека кафедры

Веб-сервис для хранения, поиска и скачивания учебных и методических материалов кафедры.

**Стек:** бэкенд Java / Spring Boot, фронтенд (веб-клиент, технология уточняется).
**Команда:** 2 человека (работа в паре).

## Документы этапа планирования

- [Видение продукта](docs/01-planning/vision.md)
- [Карта историй](docs/01-planning/story-map.md)
- [Бэклог и критерии приёмки](docs/01-planning/backlog.md)

## Структура репозитория

```
docs/        документация (docs/01-planning: планирование)
src/         исходный код (backend, frontend)
scripts/     вспомогательные скрипты (расчёты, импорт задач)
tests/       тесты
.github/     шаблоны и настройки GitHub
```

## Версии

Работа по этапам сдаётся по тегу (например, `lab1`).
